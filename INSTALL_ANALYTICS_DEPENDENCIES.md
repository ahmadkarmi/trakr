# 📊 Advanced Analytics Dependencies

Run these commands to install the required packages:

```bash
# Core data grid
npm install ag-grid-react ag-grid-community

# Charts and visualizations
npm install react-plotly.js plotly.js

# Date range picker
npm install react-date-range date-fns

# Excel export
npm install xlsx

# PDF export
npm install jspdf jspdf-autotable

# Type definitions
npm install --save-dev @types/react-plotly.js @types/plotly.js
```

## Package Breakdown

- **ag-grid-react** - Excel-like data grid with filtering, sorting, grouping
- **react-plotly.js** - Interactive data science charts
- **react-date-range** - Beautiful date range picker
- **xlsx** - Excel file generation
- **jspdf** - PDF report generation

Total size: ~5MB (gzipped)
